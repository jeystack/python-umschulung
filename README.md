# python-umschulung

My assignments from the Programming 1 module of my retraining program as an
IT specialist for application development (Fachinformatiker für
Anwendungsentwicklung, IHK) at BFZ-Essen.

The tasks come from our class worksheets. After solving them in class, I rework
each one here: I review my first version, fix the bugs I find and document what
I learned.

## How I work on each assignment

- Test the program manually with cases chosen to break it, documented as a test table
- Write down what I learned and the known limitations
- Commit each step separately using Conventional Commits
